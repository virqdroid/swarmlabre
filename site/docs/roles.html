The six roles

A run uses up to six roles. Each role is one agent with a fixed job, its own task and its own user id inside the container.

The roles#

RoleIdStartsJobPosts
Triagetriagewith the first waveReads the prepared overview and the triage files, concludes what the file is and which regions look packed or odd, and says where the other agents should look first.note, capability
Staticstaticwith the first waveReads the decompiled functions that matter, starting with the entry points and the biggest ones, and works out what they do.function
Strings/IOCiocwith the first waveReads the strings file for hosts, URLs, IP addresses, paths, registry keys, mutex names, user agents, command lines and embedded file names.ioc
Crypto/Configcryptowith the first waveLooks for cryptographic constants, keys, string-decryption routines and embedded configuration.crypto, config, function
Behaviourbehaviourwhen the board holds three findings, or the first wave has endedReads the board and the code it points to, and maps what the file can do to MITRE ATT&CK techniques.capability, technique
Reporterreporterafter every other role has finishedReads the board only and writes the text of the report and an assessment. It does not analyse the sample.none

The roles that post findings use the kinds in the last column. Any role except the Reporter can also post a dispute against another agent's finding. The board describes the kinds, the evidence levels and the disputes.

For an APK the jobs change with the file. Triage reads the package, the manifest and the components; Static reads decompiled classes; Behaviour maps to the Mobile ATT&CK matrix, and a string read from decompiled code is posted without an offset.

Which roles run#

Triage and the Reporter always run. The other four are optional: --roles static,ioc on the command line, or the launch sheet in the web UI, picks them, and the roles always run in the order of the table. An unknown role name is refused.

When each role starts#

Four roles start with the first wave. Behaviour waits until the board holds three findings, or until the four first-wave tasks have ended, so that it has something to map. The Reporter waits until every other role has finished.
