# Security

The threat model, the defences and what the repository does not claim are on the [Security page](https://swrm.re/docs/security.html).

## Reporting a problem

Use the repository's **Security** tab, "Report a vulnerability" (GitHub private vulnerability reporting). Please do not open a public issue for something that lets a sample, an agent
or a web page escape a boundary described on the Security page, run code on the host, read the model key, or make a report show something the board did not check. A report that includes a sample file is welcome;
do not send real malware you are not allowed to share. This is a one-person project: there is no response-time promise.

## Supported versions

Only the latest commit on `main`. There are no releases yet.
