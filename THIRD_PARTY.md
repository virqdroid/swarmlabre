# Third-party components

swarmlabre itself is MIT ([LICENSE](LICENSE)). This page lists everything that is **not** swarmlabre's own work: what ships in this repository, and what the Dockerfiles download when you build the images.
Nothing is vendored silently: a file that came from somebody else is listed under "In this repository"; software that is only fetched at image build is listed under "Fetched when you build the images" and is
**not** in this repository.

Checked on 2026-11-13. Each licence below was read from the project's own licence file, from the installed package's `package.json`, or from the built image, as named in the last column; none comes from memory.
Where a bundle contains further components (a fat jar, a release zip, a standalone build) the project's own licence is the one given and the bundled parts keep theirs.

## How this list is kept

A change that adds a file from somewhere else, a download to a Dockerfile, a font or a data file updates this page in the same change. `tools/build-attack-table.py` is the only way `attack.json` should change.
